# Class X Maths Practice Bank

CBSE Class X Mathematics previous-year questions (2022-2026; Standard and Basic; main, compartment and second board exams),
searchable by chapter, topic, question type, marks, year, level and difficulty. Students can mark questions done / revise later
(saved in their own browser), pick a random set of 10, and print a practice sheet.

Open `index.html` through GitHub Pages (Settings -> Pages -> Deploy from branch -> `main` / root).
No answers are included. Questions were typed in by software and checked; the original picture is shown with each question.
